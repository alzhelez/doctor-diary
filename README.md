# Дневник для врача

В течение недели надиктовываешь голосом: «опять болит голова с утра», «после кофе давление». Перед приёмом приложение собирает короткую сводку для врача: что беспокоило, когда, как часто, после чего и что помогло. Десять минут приёма уходят на дело, а не на попытки вспомнить.

**Открыть на телефоне:** https://alzhelez.github.io/doctor-diary/

## Как пользоваться

1. Откройте ссылку в Chrome (Android) или Safari (iPhone) и добавьте на главный экран: «Установить приложение» в Chrome или «Поделиться → На экран „Домой“» в Safari. Дальше оно открывается как обычное приложение и работает без интернета.
2. Нажмите на микрофон и скажите, что беспокоит, своими словами. Проверьте текст и нажмите «Сохранить запись». Под текстом видно, что приложение распознало: жалобы, время суток, замеры, лекарства, возможные причины.
3. В «Настройках» укажите дату ближайшего и прошлого приёма. За пару дней до приёма на главном экране появится ссылка на сводку.
4. На приёме откройте «Сводку» и покажите врачу экран — или нажмите «Отправить» (текстом в мессенджер), «Копировать» или «PDF».

### Что понимает приложение

| Пример фразы | Что попадёт в сводку |
|---|---|
| «опять болит голова с утра, 6 из 10» | Головная боль, утро, сила 6/10 |
| «после кофе давление 150 на 95, пульс 92» | Давление (вне нормы), связь с кофе, замер 150/95, пульс 92 |
| «выпил нурофен, через час отпустило» | Ибупрофен (Нурофен), помогло |
| «вчера вечером кололо в груди» | Боль в груди, перенесено на вчерашний вечер |
| «температура 37,8, знобит» | Повышенная температура, замер 37,8 °C |
| «голова не болит» | Ничего — отрицания не считаются жалобами |
| «вопрос врачу: можно ли мне бегать» | Отдельный блок «Вопросы к врачу» |

Распознаются около 35 жалоб (боль по частям тела, головокружение, тошнота, давление, сон, одышка, сердцебиение, отёки и др.), 17 типичных провоцирующих факторов (кофе, алкоголь, еда, нагрузка, стресс, недосып, погода, экран…), около 30 распространённых лекарств, замеры давления, пульса, температуры, сахара и сатурации. Запись, в которой ничего не распознано, всё равно попадает в сводку в разделе «Записи по дням» — ничего не теряется.

## Данные и приватность

- **Сервера нет.** Записи, даты приёмов и имя хранятся только в браузере телефона (localStorage). Наружу сводка уходит, только когда вы сами нажимаете «Отправить».
- **Голос распознаёт браузер** (Web Speech API). В Chrome звук обрабатывают серверы Google, в Safari — устройство или серверы Apple. Если это не подходит — кнопка «Написать текстом» и микрофон на клавиатуре телефона.
- **Резервная копия** — в «Настройках»: сохранить в JSON-файл и загрузить обратно (с объединением без дублей).
- Приложение ничего не диагностирует и не заменяет врача.

## Разработка

```bash
npm install
npm run dev        # локально, с доступом с телефона по Wi‑Fi (--host)
npm test           # автотесты (Vitest)
npm run build      # проверка типов и сборка в dist/
```

Стек: React 18, TypeScript, Vite, Vitest. Шрифт — Golos Text. Офлайн-режим — свой небольшой service worker (`public/sw.js`).

```
src/
  lib/
    dictionary.ts   словари: жалобы, части тела, факторы, лекарства, время суток
    parser.ts       разбор одной фразы → жалобы, замеры, лекарства, время
    summary.ts      сводка за период + текстовая версия для «Отправить»
    storage.ts      хранение на устройстве, резервная копия
    speech.ts       голосовой ввод (Web Speech API)
    *.test.ts       автотесты
  components/       экраны: запись, дневник, сводка, настройки
```

Разбор делается «на лету» при показе, а хранится только исходный текст, — поэтому улучшения словарей сразу применяются и к старым записям. Чтобы научить приложение новой жалобе или лекарству, добавьте строку в `src/lib/dictionary.ts` и тест в `src/lib/parser.test.ts`.

### Публикация

Каждый push в `main` прогоняет тесты (в часовых поясах Europe/Moscow и UTC), собирает приложение и публикует его на GitHub Pages (`.github/workflows/deploy.yml`). Один раз нужно включить Pages: **Settings → Pages → Source: GitHub Actions**.

### Ограничения

- Голосовой ввод работает в Chrome на Android и Safari на iOS 14.5+. В Firefox и встроенных браузерах мессенджеров (Telegram, VK) — только текст и микрофон клавиатуры.
- Числа распознаются цифрами, как их обычно выдаёт распознавание речи («140 на 90»); «сто сорок на девяносто» словами пока не разбирается.
- Разбор — по словарю, а не нейросетью: необычные формулировки могут не распознаться. Их видно по отсутствию меток под записью, а текст всё равно попадает в сводку.
